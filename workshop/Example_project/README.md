# Example RStudio project

This starter project accompanies Part 5 of the Data Analysis in R workshop.

1. Extract the ZIP file.
2. Open `Example_project.Rproj` in RStudio.
3. Open `scripts/import_data.R`.
4. Run the script to import `data/mercury_air.csv` with a relative path.

The `data/` folder also contains the three yearly CSV files used in the multiple-file import example in Part 5.

The project folders are:

- `data/` for input data;
- `scripts/` for R scripts;
- `outputs/` for generated tables, figures, and other results.
